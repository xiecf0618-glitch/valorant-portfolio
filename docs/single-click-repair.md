# 单击交互修正 · 2026-09-15

基线为 `main@f1ec3e9`。重新读取远端、用户两张截图、在线界面以及之前从官方视频截取的实际动作帧。

## 对用户反馈的结论

两种网页动画都不等同于实机。原枪械使用同一张侧面 PNG，X 轴倾斜压扁了侧面，并没有显示真实顶部；捷风是站姿立绘平移，没有手部、躯干和关节动作。前次将“节奏参考”当成整体动作已完成，判断过宽。

原控件也过多：进度条、左右方向、准备/二次点击、复位和键位方框占据了视觉重点。

## 当前改动

- 首页：整个枪械区域可点击。一个短提示，移除进度条、复位按钮与键位方框。自动执行两次停留、抬升/侧看/斜持和恢复；保留枪上直接拖动及键盘操作。减少枪身压扁，限制第二段姿态并下移，避免碰到名称。
- 结论页：整个角色和官方逐风技能图标属于同一个按钮。一次点击自动走准备、横向冲刺、停稳和恢复，不再让访客选择方向或二次触发。取消立绘拉伸，环境扫动只在冲刺瞬间出现，静态没有叠加地图矩形。
- 两处自动恢复，可再次点击。连点不会叠加动画，Esc、离屏和页面隐藏会清理动画。动效偏好与原全站设置保持一致。
- 保留 23 章、两页已修布局、核心论证和所有原素材；当前检视仍只有「掠影 · 狂徒」，其他章节的不同套系保留。

## 真实参考与边界

- [Riot CDN 枪械实机参考](https://valorant.dyn.riotcdn.net/x/videos/release-13.05/b21243ec-4cf0-37c0-43b4-15bf84de9d1d_default_universal.mp4)：5.4–10.3 秒，提取抬枪、两次停留、斜持与收回节奏。
- [捷风官方技能演示](https://playvalorant.com/en-us/agents/jett/)：提取准备风效、横向场景扫动、短促爆发与停稳。网页一次点击自动串起演示，不宣称游戏本身只有一次触发。

单侧 PNG 不能补出真实顶部/背面，站姿立绘不能补出真实关节动作。当前完成的是更简洁的网页交互和有限的二维表现；实机动作相似度仍未达到用户要求。继续提升该部分需要经过来源核验的多视角/动作素材或可稳定运行的模型。本站没有用视频、视频帧序列或生成画面冒充网页交互，也没有增加不稳定的外部模型。
