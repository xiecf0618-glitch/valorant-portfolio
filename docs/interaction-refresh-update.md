## 枪械与捷风

首页可切换 Reaver 狂徒、Prime 狂徒与 Oni 幻影。点击枪械触发一次轻量检视；鼠标移动产生小幅偏移，离开时复位。键盘左右方向键、Home、End 可切换，Enter/Space 使用原生按钮行为。三套原图分别为 512×156、512×148、512×116，不生成或冒充游戏内三维模型。

捷风使用原有完整立绘，点击触发一次人物轻微位移与两道风线。无自动循环、音频播放或页面滚动捕获。目录中的“减少动效”会取消动画、关闭装饰互动并保留枪械切换；系统减少动效偏好具有优先权。

## 本地验收

- 对 1440×900、1366×768、390×844 实际 iframe 视口进行检查；23 个 Scene 的标题、段落、卡片及表格均未检测到横向内容溢出。记录见 `interaction-refresh-qa/layout-checks.json`。
- 实际查看桌面与移动宽度首页、结论、瓦谷，以及用户切换/正文展开入口；枪械完整无矩形宣传背景，捷风无卡片截断。
- 点击与键盘切换会同步图片、名称、aria-pressed、焦点及 tabindex；鼠标偏移在离开后清除。
- 减少动效后枪械检视与捷风按钮 disabled，提示改为“动效已关闭”；枪械选项继续可用，再启用后装饰互动恢复。
- 动效事件与开关记录见 `interaction-refresh-qa/motion-checks.json`。当前云浏览器中 WAAPI 进入 running，但实际时间线 currentTime 在采样期间停留 0；因此只确认触发、关键帧配置与取消逻辑，不把动画中间帧的视觉播放记为通过。保留浏览器原生动画实现，未为测试环境改写生产动效。
- 移动宽度下三选项约 106×113 px，纵向滚动可从枪械区域正常进行。此项是浏览器移动宽度操作验证，不冒称真机触屏测试。
- `node --check app.js`、`node scripts/build.mjs` 与 `git diff --check` 通过；构建仍为 23 Scenes / 16 条正文来源。无新增依赖。
